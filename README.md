# Mount Vernon Control Center v0.7

## Document Library

A new Documents area supports categories, search, status filters, editing, external links, and direct uploads up to 650 KB. Larger files should remain in Google Drive, OneDrive, Dropbox, or another approved file service and be linked from the record.

## Equipment Maintenance

The Equipment area now has Inventory, Rentals, and Maintenance tabs. Maintenance records include equipment, maintenance type, issue, reported date, due date, status, priority, vendor, cost, completion date, and notes. Records can be edited, deleted, filtered, marked completed, and surfaced as overdue dashboard alerts.

## Reports

Added Document Library Index and Equipment Maintenance History reports. The Equipment Maintenance & Alerts report now combines inventory concerns and open maintenance.

## Installation

Replace the current repository files with this package, commit, wait for GitHub Pages, and press Ctrl + Shift + R.
